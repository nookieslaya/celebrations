Files were obtained from Pexels' image service as compressed 1440px-wide JPEGs. No hotlink is used at runtime. SHA-256, download URLs, author, date, license and alt descriptions are retained in sources.json. Do not remove source/license documentation when packaging these assets. Pexels permits use in websites/templates and modification; its restrictions include implied endorsement and redistribution as stock/wallpaper collections. These images form one illustrative website example, not a standalone stock-photo library.

The admin-only demonstration uses these plugin assets with reserved synthetic IDs, never attachment IDs from a customer library. Creating a fresh project from the preset uses empty customer content and no photos. The separately authorized Olivia & James example is the explicit exception: the CLI command imports these registered files through MediaService, validates the same format/size/quota rules, gives them the selected administrator as owner, and records the sample source/license marker. It does not import arbitrary paths or remote URLs, and does not mark them as a customer's original photography.

No browser, screenshot or visual review was performed. File preparation and the explicit data import are not runtime/UI verification.
